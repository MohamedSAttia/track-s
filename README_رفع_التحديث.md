# تحديث تراكفورد GRC — الشهادات والإفادات المعتمدة + استوديو GRC (عربي/English)
تصميم وبرمجة وإعداد: د. محمد عطية

## ماذا يحتوي هذا المجلد؟ (ملفات جديدة فقط — لا يستبدل أي صفحة من صفحاتك الحالية)
| الملف | الوظيفة |
|---|---|
| `tf-config.js` | **الملف الوحيد الذي يُستبدل**: نفس عنوان الخادم السابق + سطر يحمّل نظام الشهادات تلقائيًا في كل الصفحات |
| `tf-cert.js` + `vendor/tf-cert-assets.js` + `vendor/qrcode.js` + `vendor/jspdf.umd.min.js` | نظام الشهادة والإفادة: زر «🎓 شهادتي» للمتدرب، المعاينة، تنزيل PDF، رمز QR للتحقق داخل إطار بهوية تراكفورد |
| `certificates.html` | لوحة المدرب للشهادات: الطلبات، تعديل الاسم، اعتماد/إعادة/إلغاء، اعتماد جماعي، معاينة وتنزيل، متابعة لحظية للتقدّم، بيانات الشهادة |
| `studio.html` + `tf-studio-*.js` | استوديو GRC الذكي v5.0 مع زر English |
| `railway/trackford-api.index.ts` | نسخة مرجعية من كود الخادم المحدَّث (مُجهَّز على Railway كتغيير معلّق) |

## خطوات الرفع (GitHub → Vercel)
1. افتح مستودع الموقع على GitHub ← **Add file → Upload files**.
2. اسحب محتويات هذا المجلد (ما عدا مجلد `railway`) مع الحفاظ على مجلد `vendor` ← **Commit changes**.
3. Vercel ينشر تلقائيًا خلال دقيقة.

## تفعيل الخادم (Railway) — خطوة واحدة
في Railway ← مشروع **trackford-grc-live** ← ستجد تغييرًا معلّقًا على خدمة **trackford-api** ← اضغط **Deploy / Apply changes**. (أو اطلب مني «فعّل» وأنشره أنا.)
بعد التفعيل تعمل: `/api/cert` (طلب المتدرب) · `/api/cert/verify` · صفحة التحقق العامة `/verify?c=…` · إجراءات المدرب في `/api/trainer`.

## دورة العمل
1. المتدرب المسجَّل يضغط **🎓 شهادتي** ← يكتب اسمه بالإنجليزية (للشهادة) وبالعربية (للإفادة) ← يرى معاينة مباشرة ← «إرسال للمدرب».
2. المدرب يفتح **certificates.html** (أو زر «🎓 الشهادات والإفادات» في لوحة المدرب) بنفس الرقم السري ← يعدّل الاسم إن لزم ← **اعتماد**.
3. تظهر للمتدرب تلقائيًا رسالة تهنئة بالإفادة الرسمية، ويستطيع تنزيل **الشهادة** و**الإفادة** PDF.
4. أي شخص يمسح رمز QR يصل لصفحة تحقق رسمية من سجل تراكفورد (صحيحة / ملغاة / غير موجودة).
